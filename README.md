# AWS CLF Study Bot

A bilingual Discord study bot for members preparing for the AWS Certified Cloud Practitioner (CLF-C02) exam.

## Features

- Original questions aligned with the CLF-C02 exam domains.
- Private, continuous practice sessions and timed exam simulations.
- Localized study feedback and statistics in English and Brazilian Portuguese.
- Scheduled AWS learning tips for Discord servers.
